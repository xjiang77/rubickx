# math-prerequisites

topic 1.6.0 数学前置的可运行核对：导数、偏导数与梯度、链式法则。例子与 ELI5 页一致：单参数预测模型 ŷ = w·x + b，误差 e = ŷ − y，损失 L = e²。

## 证明什么

- 中心差分求出的导数与解析导数一致：L = e² 在 e = −4 处导数为 −8；w 从 3 改到 3.01 时 L 从 16 变为 15.8404，与线性近似 −16 × 0.01 一致。
- 链式法则：∂L/∂w = ∂L/∂e · ∂e/∂ŷ · ∂ŷ/∂w = (−8) × 1 × 2 = −16，与数值梯度一致。
- 多条路径相加：同一个 w 作用于两个样本 (2, 10) 与 (1, 4)，梯度为 −16 + (−2) = −18。
- 梯度下降：η = 0.05 时一步把损失从 16 降到 4（同时调 w 与 b）；只调 w 时每步损失变为上一步的 0.36 倍。
- 学习率过大：η = 0.25 时 w 在 3 与 7 之间来回，损失停在 16；η = 0.3 时发散。

## 不证明什么

- 不是自动微分引擎。手写 `Value` 与 `backward()` 的练习在 `nanochat/from-scratch/micrograd/`，按 C5 约束须本人完成，这里不提供它的实现。
