## 与 A 组的衔接

A 组的 `coords_in_basis(t, b1, b2)` 问的是：t 写成 b1、b2 的线性组合时，两个系数是多少。本目录把同一件事写成矩阵。

把新基向量按旧坐标排成列，得到 P。约定 **P 把新坐标映到旧坐标**：`v_old = P v_new`。反过来，`v_new = P^{-1} v_old`。

A 组已经核对过：`[4, 2] = 3·[1, 1] + 1·[1, −1]`，所以

`to_new_coords(change_of_basis_matrix([[1, 1], [1, -1]]), [4, 2]) == [3, 1]`。

标准基 `[[1, 0], [0, 1]]` 下，`[3, -2]` 的坐标仍是它自己。A 组在基向量共线时抛出 `ValueError`；这里两列共线同样抛出。

## 目标

- 换基矩阵的列，是新基向量写成旧坐标的结果。乘上新坐标，得到旧坐标。
- 同一个线性变换换到新基，是相似变换 `P^{-1} A P`。
- 特征向量留在自己张成的直线上。零向量不算。特征值就是那次拉伸，可以为负，也可以为 0。
- 足够多的特征向量可以当成新基。在这组基下，变换矩阵是对角的，对角元是特征值。
- 2×2 的两个特征值可以从对角元的平均数和行列式直接写出来：`m ± sqrt(m² − p)`。

## 证明什么

- 第 13 集：Jennifer 的基是 `(2, 1)` 与 `(−1, 1)`。她说的 `(−1, 2)` 是我们的 `(−4, 1)`；她说的 `(2, −3)` 是我们的 `(7, −1)`。我们的 `(3, 2)` 是她的 `(5/3, 1/3)`。`P^{-1}` 的列是 `(1/3, −1/3)` 与 `(1/3, 2/3)`。
- 课页上的 Olive 用 `(2, 3)` 与 `(−3, 2)`。Olive 的 `(−1, 2)` 是我们的 `(−8, 1)`；我们的 `(−5, −1)` 是 Olive 的 `(−1, 1)`。
- 逆时针转 90° 在我们的基下是 `[[0, −1], [1, 0]]`。换到 Jennifer 的基之后，列是 `(1/3, 5/3)` 与 `(−2/3, −1/3)`。
- 第 14 集：`[[3, 1], [0, 2]]` 的特征值是 3 和 2。x 轴上的非零向量特征值是 3；`(1, −1)` 与 `(−1, 1)` 的特征值是 2。`(1, 1)` 不是特征向量。按下面的刻度，`diagonalize_2x2` 给出列 `(1, 0)`、`(1, −1)` 和对角矩阵 `diag(3, 2)`。
- 同一集：`[[2, 2], [1, 3]]` 有特征值 1，对应方向 `(2, −1)`，变换把它固定住。另一特征值是 4，方向 `(1, 1)`。î 放大 −1、ĵ 放大 2 的矩阵是 `[[−1, 0], [0, 2]]`。整个平面放大 2 倍是 `[[2, 0], [0, 2]]`，每个非零向量都是特征向量。
- 剪切 `[[1, 1], [0, 1]]` 只有特征值 1，只有 x 轴留在自己的直线上，不能对角化。`[[−2, 1], [0, −2]]` 同样只有一个特征值 −2。逆时针转 90° 的特征多项式是 `λ² + 1`，没有实特征值。课页选择题：`[[3, 2], [2, 3]]` 的特征值是 5 和 1；`[[2, 1], [−1, 2]]` 没有实特征值。
- 斐波那契矩阵 `[[0, 1], [1, 1]]` 的特征值是 `(1±√5)/2`。课页给出的向量 `[((−1+√5)/2), 1]` 与 `[((−1−√5)/2), 1]` 分别对应这两个值。`diagonalize_2x2` 用的是同一直线上的另一刻度，见合同。
- 第 15 集：`[[3, 1], [4, 1]]` 的特征多项式是 `λ² − 4λ − 1`，特征值是 `2 ± √5`。`[[8, 4], [2, 6]]` 的平均数是 7、乘积是 40，特征值是 10 和 4。`[[2, 7], [1, 8]]` 得到 9 和 1。选择题 `[[2, 3], [2, 4]]` 得到 `3 ± √7`。三条 Pauli 矩阵里，实矩阵 `[[0, 1], [1, 0]]` 与已经对角的 `[[1, 0], [0, −1]]` 特征值都是 `±1`。含虚数的那条不在本练习里。

## 不证明什么

- 不证明 Cramer 法则。第 12 集是选看。用面积比解 `Ax = b` 不设函数；二维方程组仍由 A 组 `solve_2x2` 负责。
- 不证明一般行列式、逆的存在性定理、秩或零空间。那是 C 组。这里只用 2×2 的 `ad−bc`，以及「行列式绝对值不超过 1e-9 就当不可逆」。
- 不证明矩阵乘法作为复合的一般情形。那是 B 组。这里只把手算规模的 2×2 乘出来。
- 不做三维。第 14 集用旋转轴说明特征向量有什么用，不设 3×3 函数。
- 不返回复数。没有实特征值时抛出 `ValueError`。
- 不把「快速技巧」推广到 3×3 或 Pauli 的复矩阵。

## 合同

`eigen.py` 提供下列函数。矩阵是 `list[list[float]]`（按行），向量是 `list[float]`。返回新列表，不修改输入，也不与输入共享内部列表。整数结果与等值浮点通过 `==` 视为相同（`2 == 2.0`）。形状不对都抛 `ValueError`：不是 2×2 的矩阵、不是二维的向量、基向量不是恰好两个二维向量。

- `change_of_basis_matrix(basis_cols)`：两列是新基的旧坐标，返回 P。`|det(P)| <= 1e-9` 时抛出 `ValueError`。
- `to_old_coords(P, v_new)`：`P v_new`。P 不可逆时抛出 `ValueError`。
- `to_new_coords(P, v_old)`：`P^{-1} v_old`。P 不可逆时抛出 `ValueError`。
- `matrix_in_basis(A_old, P)`：`P^{-1} A_old P`。P 不可逆时抛出 `ValueError`。
- `is_eigenvector(A, v, tol=1e-9)`：v 非零，且 `abs(Av[0]·v[1] − Av[1]·v[0]) <= tol · max(1, |v[0]|+|v[1]|, |Av[0]|+|Av[1]|)`。零向量返回 `False`。
- `eigenvalue_of(A, v, tol=1e-9)`：`(Av · v) / (v · v)`。v 不是特征向量时抛出 `ValueError`。
- `characteristic_poly_2x2(A)`：返回 `(1, -(a+d), ad-bc)`，即首一的 `det(λI − A)`。
- `eigenvalues_from_mean_product(mean, product)`：返回 `(m + sqrt(m²−p), m − sqrt(m²−p))`。`m²−p < -1e-9` 时抛出 `ValueError`；判别式在 `−1e-9` 与 `0` 之间时当成 `0`。
- `eigenvalues_2x2(A)`：把迹的一半和行列式送进上一个函数。重根返回两个相同的数。没有实根时抛出 `ValueError`。
- `diagonalize_2x2(A, tol=1e-9)`：返回 `(P, D)`，使 `A = P D P^{-1}`，`D` 的对角元从大到小。不能对角化时抛出 `ValueError`。列的刻度：
  1. 两特征值之差不超过 `tol`，且非对角元绝对值也不超过 `tol`：P 是单位矩阵，D 是 `λI`。
  2. 重根但不是标量矩阵：`ValueError`。
  3. 没有实特征值：`ValueError`。
  4. 否则对每个 λ，取 `A−λI` 第一条有分量绝对值超过 `tol` 的行 `[u, v]`，向量先写 `[-v, u]`，再把第一个绝对值超过 `tol` 的分量翻成正的。两个分量离整数都不超过 `1e-8` 时，取整后除以最大公因数。

第 13 集要复现的数：`change_of_basis_matrix([[2, 1], [-1, 1]]) == [[2, -1], [1, 1]]`，`to_old_coords` 把 `[-1, 2]` 送到 `[-4, 1]`、把 `[2, -3]` 送到 `[7, -1]`，`to_new_coords` 把 `[3, 2]` 送到 `[5/3, 1/3]`。Olive：`[[2, 3], [-3, 2]]` 把 `[-1, 2]` 送到 `[-8, 1]`，把我们的 `[-5, -1]` 译成 `[-1, 1]`。90° 在 Jennifer 基下四舍五入到 9 位是 `[[1/3, -2/3], [5/3, -1/3]]`。

第 14 集要复现的数：`is_eigenvector([[3, 1], [0, 2]], [1, 0])` 为真且特征值为 3；`[1, -1]` 与 `[-1, 1]` 特征值为 2；`[1, 1]` 与 `[0, 0]` 不是。`diagonalize_2x2` 的 P 是 `[[1, 1], [0, -1]]`，D 是 `[[3, 0], [0, 2]]`。`[[2, 0], [0, 2]]` 对角化成单位矩阵配 `2I`。剪切与 90° 旋转抛出 `ValueError`。

第 15 集要复现的数：`characteristic_poly_2x2([[3, 1], [4, 1]]) == (1, -4, -1)`，`eigenvalues_from_mean_product(7, 40) == (10, 4)`，`eigenvalues_2x2([[2, 7], [1, 8]]) == (9, 1)`，`[[2, 3], [2, 4]]` 是 `3 ± √7`。
