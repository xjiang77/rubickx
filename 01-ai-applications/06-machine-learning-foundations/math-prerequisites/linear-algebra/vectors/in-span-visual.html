线性代数 · 向量与空间 · in_span

t 能否由 v、w 组合出来

in_span(t, v, w) 判断是否存在 a、b，使 a·v + b·w = t。按分量写开是 3 个方程、2 个未知数：用两个方程解出 a、b，再用 a、b 检验全部分量。

拖动滑块改变三个向量，或点下面的 doctest 示例。v、w 的全部组合 a·v + b·w 构成一个过原点的平面，图中绿色是其中一块；t 落在这个平面上，结果就是 True。

第 1 步：把 a·v + b·w = t 展开成三个方程

a、b 是未知数。按数乘和加法的定义把左边展开，就是你写的 scale 和 add 做的事。

最后一行左右两边都是三维向量。两个向量相等，就是第 0、1、2 个分量分别相等，所以一个向量等式等价于三个普通方程：

    未知数只有 a、b 两个，方程却有三个。两个方程就能确定 a、b，第三个方程不一定还成立，这就是 in_span 要判断的。

    绿色两行用来解 a、b，黄色一行用来检验。用哪两行由第 2 步决定。

    第 2 步：选一对分量，解出 a、b

    只看两个分量，就回到二维的 solve_2x2。图里是 v、w、t 在这两个分量上的投影 v′、w′、t′。投影共线时 d = 0，这一对解不出 a、b，要换下一对。按 (0, 1)、(0, 2)、(1, 2) 的顺序试，用第一对 d ≠ 0 的分量。

    公式推导：两个方程消元

    取选中的两个分量 i、j 的方程，先消去 b 求 a，再消去 a 求 b。左列是一般形式，右列代入当前数值。

    v、w 在三维中不共线时，三对投影中至少有一对不共线，所以一定能解出来。三对都是 d = 0，说明 v、w 本身共线，可以点上面的"v、w 共线"示例。行列式 d 的含义见二维行列式图解。

    第 3 步：用 a、b 检验全部分量

    用解出的 a、b 算出 a·v + b·w，三个分量逐个和 t 比较。用来求解的两个分量一定相等，所以真正起作用的是剩下那一个；但全部比较一遍，代码就不用记"剩下的是哪一个"。

    步骤

    对每一对分量 (i, j)，依次是 (0,1)、(0,2)、(1,2)：
  ① 取出 v、w、t 的第 i、j 个分量，
     用 solve_2x2 解 a、b
  ② 解不出（返回 None）→ 换下一对
  ③ 解出了 → 用 linear_combination
     算 a·v + b·w，逐个分量和 t 比较
     全部相等 → True；有一个不等 → False
三对都解不出 → False（v、w 共线，不符合前提）

    比较时用 abs(差) <= tol，不用 ==：a、b 由除法得到，可能带浮点误差。
