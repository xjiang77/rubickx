# Valid Sudoku(LC 36)· 五语言对比笔记

## 题目

> **LC 36. Valid Sudoku（有效的数独）· Medium** · <https://leetcode.cn/problems/valid-sudoku/>

判断一个 9 x 9 的数独是否有效。**只需要根据以下规则验证已经填入的数字**：
1. 每一行的数字 1-9 不能重复；
2. 每一列的数字 1-9 不能重复；
3. 以粗实线分隔的 9 个 3 x 3 宫内，数字 1-9 不能重复。
空白格用 '.' 表示。注意：一个有效的数独（部分已填）**不一定是可解的**，
只需要按上面三条规则验证已填入的数字即可。

**示例**

```
合法棋盘（LC 官方样例）-> true
把左上角的 5 改成 8（与同宫的 8 冲突）-> false
```

**约束**

- board.length == 9
- board[i].length == 9
- board[i][j] 是一位数字 '1'-'9' 或者 '.'


## 核心思路(语言无关)

只验证"已填数字不冲突",**不需要求解**。每个数字要同时满足三个约束:所在**行**、**列**、**3×3 宫**内唯一。一次扫描,维护 3 组"已见"状态各 9 份,任何一处重复立即返回 false。

关键公式:**宫下标 `b = (r/3)*3 + c/3`**(整除),把二维宫坐标压成 0..8。这个映射在 N-Queens、棋盘类题里反复出现,必须张口就来。

## 五语言"已见状态"的三档表示

| 档次 | 表示 | 使用语言 | 空间 |
|---|---|---|---|
| 集合 | `set` / `Set` | Python、JS | 每格一个哈希条目 |
| 布尔数组 | `boolean[9][9]` | Java | 243 字节级 |
| **位掩码** | `[9]uint16`,bit d = 数字 d+1 | Go | 每单元 2 字节,共 54 字节 |

三档语义完全等价,越往下越省空间/越快,越往上越直白。**面试策略:先写 set 版保正确,被追问优化再降到 bitmask**。

### 各语言要点

- **Python**:`[set() for _ in range(9)]` 注意不能写 `[set()] * 9`——那是 9 个引用指向同一个 set,状态全串了。这是 Python 可变对象最经典的坑。
- **Go**:位掩码版。`uint16(1) << (ch - '1')` 生成该数字的 bit;`&` 查重、`|=` 登记。`[9]uint16` 是**值类型数组**,零值即全空,无需初始化——bitmask + 数组零值,Go 在这题最紧凑。
- **JavaScript**:`Array.from({length: 9}, () => new Set())` 每次调用工厂函数,生成 9 个**独立** Set;`new Array(9).fill(new Set())` 则和 Python 的 `* 9` 一样是同一个引用 ×9,同款坑。
- **Java**:`boolean[9][9]` 原始数组无装箱、缓存友好,比 `HashSet<Character>` 快一个量级;`rows[r][d] = cols[c][d] = boxes[b][d] = true` 连等赋值一行登记三处。
- **Scala**:完全不同的思路——for 推导式把每个格子展开成三条 `(维度, 下标, 值)` 证据,`seen.distinct.size == seen.size` 判定全局无重复。**把"逐格检查"翻译成了"集合性质断言"**,是函数式建模的好样本;代价是不能早退(全量生成再判断),O(81) 下无所谓。

## 测试构造技巧

9 行字符串比二维字面量可读得多,五份测试都用 `"53..7...."` 形式 + 各语言的 to_board 转换(`list(row)` / `[]byte(row)` / `split('')` / `toCharArray` / `map(_.toCharArray)`)。构造非法棋盘用"改一格"生成:改 (0,0) 为 8 制造**宫重复**、改 (0,2) 为 5 制造**行重复**,精确命中单一约束。

## 复杂度

固定 9×9:时间 O(81),空间 O(1)(常数上限)。谈复杂度时说清"对一般 n×n 是 O(n²) 时间、O(n²) 空间(set 版)或 O(n²/8) 位(bitmask 版)"。

## 易错点

1. Python `[set()] * 9` / JS `fill(new Set())` → 9 个引用同一对象,必用推导式/工厂函数。
2. 宫下标写成 `r/3 + c/3*3` 或 `(r%3)*3 + c%3` → 映射错乱;记死 `(r/3)*3 + c/3`。
3. 忘了跳过 `'.'` → 空格互相"重复",全盘 false。
4. 想成"验证数独可解" → 题目只要"已填不冲突",别多做。
