Backpropagation（反向传播）：求出每个 parameter 的 gradient

神经网络训练中计算 gradient（梯度）的方法：从 loss（损失）出发，沿 computational graph（计算图）反向应用 chain rule（链式法则）。

概述

背景

神经网络通过调整 parameter（参数）进行学习；在 LLM 中 parameter 是各层的 weight（权重），GPT-3 有 1750 亿个。预测与正确答案的差距由 loss function（损失函数）量化为 loss（损失），训练的目标是使 loss 最小化。每一步训练都需要 loss 对每个 parameter 的 gradient（梯度）：该 parameter 增大时，loss 增大还是减小、变化多快。Backpropagation 只需一次 forward pass（前向计算）和一次反向计算，就能求出全部 parameter 的 gradient；不用它怎样求、计算量差多少，见第 6 屏。

  1. Forward pass算出预测和 loss
  2. Backpropagation求出每个 parameter 的 gradient
  3. Update沿 gradient 反方向调整 parameter

训练过程重复执行这三步

定义与示例

Backpropagation（反向传播）是计算 loss 对模型全部 parameter 的 gradient 的算法：在 computational graph（计算图，节点为中间结果，箭头为运算）上，从 loss 出发反向应用 chain rule（链式法则）。以房价预测为例：模型根据房屋面积估算成交价，唯一的 parameter 是单价。

单位说明：本页公式和图中，面积以 100 平方米为 1 个单位，房价以 100 万元为 1 个单位：x = 2 表示 200 平方米，ŷ = 6 表示 600 万元。单价 w 的单位不变，仍是万元／平方米（100 万元 ÷ 100 平方米 = 1 万元／平方米）。训练前缩放输入是机器学习的常规做法（feature scaling，特征缩放）。

示例

  1. Forward pass：一套面积 200 平方米的房屋，模型当前的单价估计为 3 万元／平方米，预测房价 600 万元。
  2. 计算 loss：Loss function 取误差的平方：loss =（预测房价 − 实际成交价）²。实际成交价 1000 万元，预测低了 400 万元，即误差 −4，loss 为 16。
  3. Backpropagation：从 loss 出发沿 computational graph 反向逐个运算计算，得到 loss 对单价的 gradient −16。
  4. Parameter update：Gradient 为负，说明调高单价会使 loss 减小；按 learning rate（学习率）0.05 调整，单价由 3 调到 3.8 万元／平方米。
  5. 重复迭代：以新的单价重复以上四步：单价逐轮接近实际的 5 万元／平方米，loss 逐轮下降；gradient 随误差缩小，每轮的调整量随之减小。

公式

ŷ = w·x模型：预测房价 = 单价 × 面积L = (ŷ − y)² = (w·x − y)²loss function；记误差 e = ŷ − y，则 L = e²∂L/∂w = ∂L/∂e · ∂e/∂ŷ · ∂ŷ/∂w = 2e · 1 · xchain rule，各因子为 local derivative（局部导数）w ← w − η · ∂L/∂wgradient descent，η 为 learning rate代入 x = 2，y = 10，w = 3：  ŷ = 6，e = −4，L = 16∂L/∂w = (−8) × 1 × 2 = −16，  w ← 3 − 0.05 × (−16) = 3.8

起源与发展

该算法的提出早于深度学习。1970 年，Linnainmaa 提出 reverse-mode automatic differentiation（反向模式自动微分，简称 reverse-mode AD）；1982 年，Werbos 将其用于训练神经网络；1986 年，Rumelhart、Hinton 与 Williams 通过实验表明它能使 hidden layer（隐藏层）学到有效的 representation（表示），此后广泛应用。2012 年前后，GPU 训练使大型网络成为可能。目前 PyTorch 等框架用 autograd 自动执行 backpropagation。

  1. 1970Reverse-mode ADLinnainmaa
  2. 1982用于训练神经网络Werbos
  3. 1986Hidden layer 能学到 representationRumelhart 等
  4. 2012GPU 训练大型网络AlexNet
  5. 当前框架自动执行（autograd）PyTorch 等

逐步推演

推演沿用上述房价预测：一个 parameter w（单价），一个样本 (x, y) = (2, 10)，即面积 200 平方米、成交价 1000 万元。LLM 的 computational graph 包含大量运算与数十亿个 parameter，求 gradient 的规则与本例相同。所需数学为 derivative、partial derivative 与 gradient、chain rule，各有一页图解。

本例说明以下要点：

  1. Gradient 沿 computational graph 反向传递，每经过一个运算，乘以该运算的 local derivative，即 chain rule。
  2. 同一个 parameter 影响多条路径时（例如一个 batch 中的多个样本），各路径传回的 gradient 相加。
  3. Gradient 的符号给出 parameter 的调整方向，绝对值表示 loss 对该 parameter 的敏感程度。
1 · Forward pass
ŷ = w·x = 6，  e = ŷ − y = −4，  L = e² = 16

Forward pass 从输入与 parameter 开始，按依赖顺序计算每个中间结果：预测房价、误差、loss。Backpropagation 需要使用这些中间值，因此 forward pass 会将其保存。

2 · Local derivative
∂ŷ/∂w = x = 2，  ∂e/∂ŷ = 1，  ∂L/∂e = 2e = −8

每个运算只涉及自身的输入与输出：输入增加一个微小量时，输出变化的倍数即该运算的 local derivative。三个运算的 local derivative 均可直接写出，无需了解整个模型。

3 · Chain rule
∂L/∂w = ∂L/∂e · ∂e/∂ŷ · ∂ŷ/∂w = (−8) × 1 × 2 = −16

从 L 出发沿 computational graph 反向计算，每经过一个运算，乘以该运算的 local derivative，即 chain rule。数值验证：w 由 3 改为 3.01，L 由 16 变为 15.8404，减少约 0.16，与 16 × 0.01 一致。

4 · 多条路径
L = (2w − 10)² + (w − 4)²，  ∂L/∂w = −16 + (−2) = −18

训练通常以 batch（批次）为单位使用样本。加入第二套房屋：面积 100 平方米（x = 1），成交价 400 万元（y = 4）。同一个 w 作用于两个样本，形成两条通向总 loss 的路径，w 的 gradient 为两条路径的 gradient 之和；若只计入其中一条，所得 gradient 不正确。

5 · Gradient descent
w ← w − η · ∂L/∂w = 3 − 0.05 × (−16) = 3.8

回到单个样本。Gradient 为负，表示 w 增大时 loss 减小，因此沿 gradient 的反方向更新 w，即 gradient descent（梯度下降）。取 learning rate η = 0.05，一步后 w = 3.8，预测房价 7.6（760 万元），loss 由 16 降至 5.76；此后每步 loss 变为上一步的 0.36 倍。

6 · 为什么不逐个试
∂L/∂w ≈ [L(w + h) − L(w)] / h = (15.8404 − 16) / 0.01 = −15.96

第 3 屏的数值验证就是 finite difference（有限差分）：把一个 parameter 改动一个微小量，重新执行一次 forward pass，用 loss 的变化量除以改动量。它每次只能得到一个 parameter 的 gradient。Backpropagation 一次反向计算就得到全部 gradient，反向计算的开销约为 forward pass 的 2 倍。

方法求出全部 gradient 的计算量GPT-3（1750 亿个 parameter）
Finite differenceparameter 有多少个，就执行多少次 forward pass约 1750 亿次 forward pass
Backpropagation1 次 forward pass 加 1 次反向计算（反向计算约为 forward pass 的 2 倍）约相当于 3 次 forward pass

适用条件与局限

Local derivative 只在当前取值附近成立，learning rate 过大时这一线性近似失效。本例中 learning rate 达到 0.25 即不再收敛：取 η = 0.25，w 由 3 变为 7，预测房价 14（1400 万元），误差 +4，loss 仍为 16，此后在 3 与 7 之间振荡；更大时发散。此外，gradient 为 0 不一定表示模型已学好，activation function（激活函数）饱和或 computational graph 断开同样会使 gradient 为 0。

工程应用

  • loss 不下降或变为 NaN首先检查 gradient：若全为 0，检查 computational graph 是否被 detach() 或 in-place 操作断开、activation function 是否饱和；若持续增大，检查 learning rate 与 exploding gradient（梯度爆炸），可采用 gradient clipping（梯度裁剪）。
  • 显存不足Backpropagation 需要 forward pass 保存的中间结果（activation，激活值），其占用随 batch 大小与网络深度增加。可减小 batch，或采用 activation checkpointing，以重复计算换取显存。
  • Fine-tuning（微调）中冻结 parameter；LoRA 节省显存的原因被冻结的 parameter 不计算 gradient，也无需保存 optimizer（优化器）状态。LoRA 只训练插入的低秩矩阵，需要 gradient 的 parameter 数量减少若干个数量级。
  • Inference（推理）时关闭 gradient 计算Inference 只执行 forward pass；使用 torch.no_grad() 后不再保存 backward pass 所需的中间结果，速度更快、显存占用更低。Preference learning 中的 reference model 同样只执行 forward pass。

Backpropagation 在 computational graph 上从 loss 出发反向应用 chain rule：每经过一个运算乘以其 local derivative，多条路径的 gradient 相加，由此得到 loss 对每个 parameter 的 gradient。
