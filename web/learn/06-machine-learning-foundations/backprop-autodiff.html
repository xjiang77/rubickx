反向传播：沿计算图求出每个参数的梯度

神经网络训练中计算梯度的方法：从损失出发，沿计算图反向应用链式法则。

先弄清楚

为什么要懂它

神经网络通过调整参数来减小损失。每次调整都要知道：某个参数增加一点，损失是增大还是减小、变化多少，也就是损失对这个参数的梯度。参数少则数百万、多则上千亿，逐个试探的代价无法承受。反向传播只需一次反向计算，就能得到全部参数的梯度，计算量与一次前向计算同一量级。

  1. 前向算出损失
  2. 反向传播求出每个参数的梯度
  3. 更新沿梯度反方向调整参数

训练时这三步反复执行

它是什么

反向传播是在计算图上求梯度的方法。以 L = (x + 3)² 为例：前向时依次算出 u = 5、L = 25；反向时从 ∂L/∂L = 1 开始，每经过一步就乘上这一步的局部导数，依次得到 ∂L/∂u = 10、∂L/∂x = 10。

从哪里来

这个算法比深度学习早得多。1970 年，Linnainmaa 提出反向模式自动微分；1982 年，Werbos 将它用于训练神经网络；1986 年，Rumelhart、Hinton 和 Williams 通过实验表明，它能让网络的隐藏层学到有用的表示，此后广泛使用。受算力和数据限制，之后很长时间只能训练较小的网络；2012 年前后，GPU 训练使大型网络成为可能。如今 PyTorch 等框架会自动完成反向传播（autograd）。

  1. 1970反向模式自动微分Linnainmaa
  2. 1982用于训练神经网络Werbos
  3. 1986实验表明隐藏层能学到表示Rumelhart 等
  4. 2012GPU 训练大型网络AlexNet
  5. 今天框架自动完成PyTorch 等

用一个例子推演一遍

例子只有两步运算：输入 x = 2，先加 3 得到 u，再平方得到损失 L，即 L = (x + 3)²。真实网络的计算图有成千上万步、上亿个参数，求梯度的规则与这里相同。

这个例子要说明：

  1. 梯度沿计算图反向传递，每经过一步，就乘上这一步的局部导数，这就是链式法则。
  2. 一个变量影响多条路径时，各条路径传回的梯度相加。
  3. 梯度的正负给出参数的调整方向，大小表示损失对它有多敏感。
1 · 前向计算
u = x + 3 = 5，  L = u² = 25

从输入开始，按顺序算出每个中间变量，最后得到损失。反向传播要用到这些中间值，所以前向计算时会把它们保存下来。

2 · 局部导数
∂u/∂x = 1，  ∂L/∂u = 2u = 10

局部导数只描述一步运算：输入增加一点时，这一步的输出变化多少倍。加 3 的局部导数恒为 1；平方的局部导数是 2u，在 u = 5 处等于 10。

3 · 链式法则
∂L/∂x = ∂L/∂u · ∂u/∂x = 10 × 1 = 10链式法则

从 L 出发反向传递，每经过一步就乘上这一步的局部导数。x 从 2 增加到 2.01 时，L 从 25 变为 25.1001，增加约 0.1，正好是 10 × 0.01，与算出的梯度一致。

4 · 多条路径
L = 3a + a²，  ∂L/∂a = 3 + 2a = 3 + 10 = 13

a 同时经过“乘 3”和“平方”两条路径影响 L，两条路径各自传回一个梯度，a 的梯度是两者之和。只保留一条就会算错，这是手写自动微分最常见的错误。

5 · 梯度下降
x ← x − η · ∂L/∂x = 2 − 0.1 × 10 = 1，  L = (1 + 3)² = 16

梯度为正，说明 x 增大时 L 也增大，所以沿梯度的反方向更新 x。取学习率 η = 0.1，一步之后 x = 1，L 从 25 降到 16；此后每一步，L 都变为上一步的 0.64 倍。

适用边界

局部导数只在当前取值附近成立，学习率过大时这种近似就会失效。本例取 η = 1，x 会从 2 跳到 −8，此时 u = −5，损失仍是 25，之后在两个值之间来回振荡。另外，梯度为 0 不一定说明已经学好，激活函数饱和或计算图被断开也会让梯度为 0。

反向传播就是在计算图上从损失出发反向应用链式法则：每一步乘上局部导数，多条路径的梯度相加，得到损失对每个参数的梯度。
