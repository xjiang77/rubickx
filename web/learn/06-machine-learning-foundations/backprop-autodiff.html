反向传播：沿计算图求出每个参数的梯度

反向传播（backpropagation）是神经网络训练中计算梯度的方法：从损失出发，沿计算图反向应用链式法则。

先弄清楚

为什么要懂它

神经网络靠调整参数（parameter）来学习：预测和正确答案差得越远，损失（loss）越大，训练就是不断调整参数，让损失变小。每次调整都要知道：某个参数增加一点，损失是增大还是减小、变化多少，这就是损失对这个参数的梯度（gradient）。参数少则数百万、多则上千亿，逐个试探的代价无法承受。反向传播只需一次反向计算，就能得到全部参数的梯度，计算量与一次前向计算同一量级。

  1. 前向算出预测和损失
  2. 反向传播求出每个参数的梯度
  3. 更新沿梯度反方向调整参数

训练时这三步反复执行

它是什么

看一个只有一个参数的预测模型：输入 x = 2，参数 w = 3，模型预测 ŷ = w·x = 6；正确答案 y = 10，误差 e = ŷ − y = −4；损失取误差的平方，L = e² = 16。把这一串运算画出来，每个节点是一个中间结果，每条箭头是一次运算，这张图叫计算图（computational graph）。反向传播（backpropagation）从 L 出发，沿计算图往回走，每经过一步就乘上这一步的导数，最后得到 ∂L/∂w = −16：负号表示 w 增大时损失减小，所以 w 应该调大。

从哪里来

这个算法比深度学习早得多。1970 年，Linnainmaa 提出反向模式自动微分；1982 年，Werbos 将它用于训练神经网络；1986 年，Rumelhart、Hinton 和 Williams 通过实验表明，它能让网络的隐藏层学到有用的表示，此后广泛使用。受算力和数据限制，之后很长时间只能训练较小的网络；2012 年前后，GPU 训练使大型网络成为可能。如今 PyTorch 等框架会自动完成反向传播（autograd）。

  1. 1970反向模式自动微分Linnainmaa
  2. 1982用于训练神经网络Werbos
  3. 1986实验表明隐藏层能学到表示Rumelhart 等
  4. 2012GPU 训练大型网络AlexNet
  5. 今天框架自动完成PyTorch 等

用一个例子推演一遍

沿用上面的预测模型：一个参数 w，一个样本 (x, y) = (2, 10)。真实网络的计算图有成千上万步、上亿个参数，求梯度的规则与这里相同。需要的数学只有三样：导数、偏导数与梯度、链式法则，点开可看一页图解。

这个例子要说明：

  1. 梯度沿计算图反向传递，每经过一步，就乘上这一步的局部导数，这就是链式法则。
  2. 同一个参数影响多条路径时（例如一批样本），各条路径传回的梯度相加。
  3. 梯度的正负给出参数的调整方向，大小表示损失对它有多敏感。
1 · 前向计算
ŷ = w·x = 6，  e = ŷ − y = −4，  L = e² = 16

从输入和参数开始，按顺序算出每个中间结果：预测、误差、损失。反向传播要用到这些中间值，所以前向计算时会把它们保存下来。

2 · 局部导数
∂ŷ/∂w = x = 2，  ∂e/∂ŷ = 1，  ∂L/∂e = 2e = −8

每一步运算只看自己：输入增加一点时，这一步的输出变化多少倍，这就是它的局部导数（local derivative）。三步的局部导数都能直接写出来，不需要知道整个模型。

3 · 链式法则
∂L/∂w = ∂L/∂e · ∂e/∂ŷ · ∂ŷ/∂w = (−8) × 1 × 2 = −16

从 L 出发往回走，每经过一步就乘上这一步的局部导数，这就是链式法则（chain rule）。核对一下：w 从 3 改到 3.01，L 从 16 变为 15.8404，减少约 0.16，正好是 16 × 0.01。

4 · 多条路径
L = (2w − 10)² + (w − 4)²，  ∂L/∂w = −16 + (−2) = −18

训练时一次会用一批样本（batch）。同一个 w 作用在两个样本上，就有两条路径通向总损失；每条路径传回一份梯度，w 的梯度是它们的和。只保留一条，结果就错了。

5 · 梯度下降
w ← w − η · ∂L/∂w = 3 − 0.05 × (−16) = 3.8

梯度为负，说明 w 增大时损失减小，所以沿梯度的反方向更新 w，这就是梯度下降（gradient descent）。取学习率（learning rate）η = 0.05，一步之后 w = 3.8，预测 7.6，损失从 16 降到 5.76；之后每一步，损失都变为上一步的 0.36 倍。

适用边界

局部导数只在当前取值附近成立，学习率过大时这种近似就会失效。本例的学习率超过 0.25 就无法收敛：取 η = 0.25，w 从 3 跳到 7，预测 14，误差 +4，损失仍是 16，之后在 3 和 7 之间来回；再大就会发散。另外，梯度为 0 不一定说明已经学好，激活函数饱和或计算图被断开也会让梯度为 0。

在 AI 工程里什么时候用得上

  • loss 不降，或者变成 NaN先看梯度：全为 0，查计算图是否被 detach() 或 in-place 操作断开、激活是否饱和；越来越大，查学习率和梯度爆炸，考虑梯度裁剪。
  • 显存不够反向传播要用前向保存的中间结果，batch 越大、网络越深占得越多。可以减小 batch，或用 activation checkpointing 以重算换显存。
  • 微调时冻结哪些参数，LoRA 为什么省显存冻结的参数不求梯度，也不需要保存优化器状态。LoRA 只训练插入的小矩阵，需要梯度的参数少了几个数量级。
  • 推理为什么要关掉梯度推理只做前向，用 torch.no_grad() 就不保存反向要用的中间结果，更快也更省显存。偏好训练里的 reference model 也只做前向。

反向传播就是在计算图上从损失出发反向应用链式法则：每一步乘上局部导数，多条路径的梯度相加，得到损失对每个参数的梯度。
