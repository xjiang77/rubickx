定义与示例

Vector 是一类数学对象，其上定义了两种运算——两个 vector 相加，以及 vector 乘以一个数（scalar，标量）——且运算结果仍是 vector。几何上它是从原点出发的箭头，由长度与方向决定；数值上它是有序的数字列表，顺序与长度均有意义。示例采用屏幕颜色：一种颜色由红、绿、蓝三个分量表示，是一个三维 vector。

示例

  1. 表示：把颜色记为三个 0 到 255 的数。红色为 (255, 0, 0)，黄色为 (255, 255, 0)。
  2. 数乘：红色乘以 0.5，每个分量减半，得到 (127.5, 0, 0)，即亮度减半的红。
  3. 相加：0.5 倍红色与 0.5 倍黄色逐分量相加，得到 (255, 127.5, 0)，屏幕上显示为橙色。缩放后相加的结果称为 linear combination。
  4. Span：只用红与绿两种颜色，无论系数怎样取，蓝分量始终为 0，能配出的颜色只占全部颜色中的一个平面，这个平面就是红与绿的 span。
  5. Basis：红、绿、蓝任一种都配不出另外两种，称为 linearly independent（线性无关）；三者又能配出全部颜色，因此构成颜色空间的一个 basis，(R, G, B) 即颜色在这组 basis 下的坐标。

公式

v + w = [v₁ + w₁, v₂ + w₂, v₃ + w₃]，  c·v = [cv₁, cv₂, cv₃]加法与数乘均逐分量进行a·v + b·wlinear combination0.5·(255, 0, 0) + 0.5·(255, 255, 0) = (255, 127.5, 0)

起源与发展

Vector 一词来自 Hamilton 1843 年的 quaternion（四元数）。Grassmann 1844 年的《扩张论》已定义 linear independence、span 与维数，但长期无人理解；Peano 1888 年给出 vector space（向量空间）的公理化定义，1920 年前后由 Banach、Noether 等人各自重新发现；Halmos 1942 年的教材确立了以 vector space 为起点的现代讲法。

  1. 1843Quaternion 与 vector 一词Hamilton
  2. 1844Linear independence、span、维数Grassmann
  3. 1888Vector space 公理Peano
  4. 约 1920概念被重新发现Banach、Noether 等
  5. 1942《有限维向量空间》Halmos

逐步推演

推演在平面上进行，使用两个 vector v = [3, 1] 与 w = [1, 2]（知识正文 02 的例子），第 4 屏扩展到三维，第 5 屏回到平面。屏幕上的一格为 1 个单位。

本例说明以下要点：

  1. 坐标是对 basis vector 的缩放：(3, −2) 表示 3 倍的 î 加 −2 倍的 ĵ。
  2. Linear combination 的几何意义是首尾相接：缩放后的箭头依次接上，终点即结果。
  3. Span 由 vector 是否共线决定；basis 要求 linearly independent 且 span 整个空间。
  4. 消元得到的系数 d 是 v 与 w 围成的平行四边形的有向面积，d = 0 即共线。
1 · 坐标即缩放 basis vector
(3, −2) = 3·(1, 0) + (−2)·(0, 1) = (3, 0) + (0, −2)

î 与 ĵ 是长度为 1、分别指向 x 与 y 方向的 basis vector。每个坐标是一个 scalar，缩放对应的 basis vector；两段缩放后的箭头首尾相接，终点即该 vector。

2 · Linear combination 首尾相接
a·v + b·w：  2·(3, 1) + 1·(1, 2) = (6, 2) + (1, 2) = (7, 4)

把 v 拉长到 2 倍，再把 w 平移到它的尖端，从原点到 w 尖端的箭头即 linear combination 的结果。数值上先数乘再逐分量相加，与图中的首尾相接一致。

3 · Span：共线与不共线
a·v + b·(2v) = (a + 2b)·v，  始终是 v 的倍数

Span 是全部 linear combination 的集合。u 是 v 的 2 倍，任何组合仍是 v 的倍数，span 只是一条直线；w 不与 v 共线，两个系数各自独立，span 覆盖整个平面。

4 · Linearly independent 与 basis
(1, 1, 2) = 1·(1, 0, 1) + 1·(0, 1, 1)，  故 v₁、v₂、v₃ linearly dependent，span 是一张平面

去掉某个 vector 而 span 不变，这组 vector 即 linearly dependent；每个 vector 都为 span 增加一个维度，则 linearly independent。既 linearly independent 又 span 整个空间的一组 vector 称为 basis，此时每个 vector 的坐标唯一。

5 · 消元与 determinant
d = vxwy − vywx = 3·2 − 1·1 = 5
v 换成 t：7·2 − 4·1 = 10 = 2·d，故 a = 2；  u = (6, 2)：3·2 − 1·6 = 0

消元时第一式乘 wy、第二式乘 wx 后相减，b 被消去，a 的系数为 d，本例 5a = 10。几何上 d 是 v 与 w 围成的平行四边形的有向面积：外框 12 减去六块空白 7。把 v 换成 t 计算同一式，w 与自身围成的面积为 0，结果为 a·d。d = 0 时 v 与 w 共线，方程组没有唯一解。

适用条件与局限

本页只处理二维、三维与实数 scalar；n 维与其他数域的推广见 abstract vector space（抽象向量空间）。Basis 不唯一，î 与 ĵ 只是最常用的一组；同一个 vector 在不同 basis 下坐标不同。判断多个 vector 是否 linearly independent，一般需要计算 rank（秩）或 determinant，"随机三个 vector 几乎一定 linearly independent"是概率性的说法。第 5 屏只讨论 2×2 determinant；三维对应 3×3 determinant（平行六面体的有向体积），系统讲解待知识正文 04。

工程应用

  • Embedding 是 vector语言模型把每个 token 映射为一个 d 维 vector，模型内部各层传递的也是同样维数的 vector；分量的含义由训练决定，不对应可命名的属性。
  • Attention 的输出是 linear combinationAttention(Q, K, V) 的每一行是 V 各行的 linear combination，系数由 softmax 给出，非负且和为 1，因此输出落在 value vector 的 span 内，并且位于它们围成的区域之中。
  • LoRA 的更新落在低维 span 内LoRA 把权重更新写成 B·A，B 只有 r 列；更新矩阵的每一列都是这 r 个列 vector 的 linear combination，因此全部列位于维数不超过 r 的子空间内，这正是"低秩"的含义。

Vector 由加法与数乘定义；缩放后相加得到 linear combination，全部组合构成 span；linearly independent 且 span 整个空间的一组 vector 是 basis，坐标即对 basis 的缩放系数。
