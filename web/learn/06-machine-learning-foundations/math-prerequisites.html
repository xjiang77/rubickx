概述

背景

Backpropagation 的每一步都是求导运算：各运算的 local derivative（局部导数）是 derivative，要求的 gradient 由 partial derivative 组成，将各步连接起来的是 chain rule。掌握这三个概念后，backpropagation 可归结为按依赖顺序执行的乘法与加法。本页只介绍 backpropagation 所需的部分。

  1. Derivative局部变化率
  2. Partial derivative 与 gradient多个 parameter 的调整方向
  3. Chain rule复合运算的求导
  4. Backpropagation一次求出全部 gradient

定义与示例

三者都用于描述输入变化引起的输出变化：derivative（导数）是单变量函数在某一点的变化率；partial derivative（偏导数）是多变量函数中只改变一个变量时的变化率；gradient（梯度）是全部 partial derivative 组成的向量；chain rule（链式法则）指出复合运算的 derivative 等于各步 derivative 之积。示例沿用房价预测，模型用单价与一个固定部分（车位、装修等与面积无关的价值）两个 parameter（参数）估算房价。

单位说明：与 backpropagation 页相同：面积以 100 平方米为 1 个单位，房价以 100 万元为 1 个单位，x = 2 表示 200 平方米，ŷ = 6 表示 600 万元；单价 w 仍以万元／平方米计，固定部分 b 以 100 万元为 1 个单位。

示例

  1. 设定：一套面积 200 平方米的房屋，模型当前的单价估计为 3 万元／平方米、固定部分为 0，预测 600 万元，比实际成交价 1000 万元低 400 万元。Loss function（损失函数）取误差的平方：loss =（预测房价 − 实际成交价）²，此时 loss（损失）为 16。
  2. Derivative：预测每提高 1 万元（误差缩小 0.01），loss 约减少 0.08；这个变化率 −8 就是 loss 对误差的 derivative。
  3. Partial derivative 与 gradient：只调单价，或只调固定部分，各得到一个变化率，两者都为负；合在一起就是 gradient，说明两个 parameter 都应调高。
  4. Chain rule：Loss 经过“乘以面积、减去成交价、平方”三步才依赖单价；三步各自的变化率相乘，即 loss 对单价的 derivative。

公式

ŷ = w·x + b模型：预测房价 = 单价 × 面积 + 固定部分L = (ŷ − y)² = e²loss function，e 为误差dL/de = 2ederivative∇L = (∂L/∂w, ∂L/∂b) = (2e·x, 2e)partial derivative 与 gradient∂L/∂w = ∂L/∂e · ∂e/∂ŷ · ∂ŷ/∂w = 2e · 1 · xchain rule代入 x = 2，y = 10，w = 3，b = 0：  e = −4，dL/de = −8，∇L = (−16, −8)

起源与发展

17 世纪后期，牛顿与莱布尼茨分别建立 calculus（微积分）；dy/dx 记法源自莱布尼茨，chain rule 在该记法下表达最为直接。1847 年，Cauchy 提出沿负 gradient 方向逐步逼近极值的方法，即 gradient descent（梯度下降）的早期形式。1970 年起，reverse-mode automatic differentiation（反向模式自动微分）将 chain rule 实现为可自动执行的算法，即后来用于训练神经网络的 backpropagation。

逐步推演

示例只用一个样本 (x, y) = (2, 10)，即面积 200 平方米、成交价 1000 万元；parameter 初值为 w = 3、b = 0。第 1 屏介绍 derivative，第 2、3 屏介绍 partial derivative、gradient 与 gradient descent，第 4 屏介绍 chain rule。

本例说明以下要点：

  1. Derivative 是局部变化率：输入改变一个小量时，输出的改变量约为 derivative 与该小量之积。
  2. Gradient 由各 parameter 的 partial derivative 组成，指向 loss 增大最快的方向；沿反方向移动，loss 下降。
  3. 复合运算的 derivative 等于各步 derivative 之积；存在多条路径时，各路径的结果相加。
1 · Derivative
L′(e) = 2e = −8，  L(−3.99) ≈ 16 + (−8) × 0.01 = 15.92

Derivative 即曲线在该点的斜率（slope）。e 由 −4 增至 −3.99，L 由 16 变为 15.9201，与按斜率估计的 16 − 0.08 基本一致。改动越小，估计越准确，这称为 local linear approximation（局部线性近似）。

2 · Partial derivative 与 gradient
∂L/∂w = 2e·x = −16，  ∂L/∂b = 2e = −8，  ∇L = (−16, −8)

存在两个 parameter 时，分别只改变其中一个，得到两个 partial derivative；二者组成的向量即 gradient。Gradient 指向 loss 增大最快的方向，沿其反方向移动，loss 下降。两个 partial derivative 均为负，因此 w 与 b 都应增大，与预测房价 600 万元低于成交价 1000 万元相符。

3 · Gradient descent
θ ← θ − η · ∇L：  (3, 0) − 0.05 × (−16, −8) = (3.8, 0.4)

Gradient descent 每步沿负 gradient 方向移动一段距离，步长由 learning rate（学习率）η 决定。取 η = 0.05，一步后 loss 由 16 降至 4。

4 · Chain rule
∂L/∂w = ∂L/∂e · ∂e/∂ŷ · ∂ŷ/∂w = (−8) × 1 × 2 = −16

Loss 经过三个运算才依赖 w，每个运算各有一个 derivative：乘以 x 为 2，减去 y 为 1，平方为 −8。三者之积即 loss 对 w 的 derivative。

适用条件与局限

本页只涉及标量与两个 parameter。真实网络的 parameter 为向量与矩阵，求导需要 Jacobian（雅可比矩阵），由框架自动处理，原理与本页相同。Derivative 给出的是局部近似，改动过大时误差增大，这也是 learning rate 不能过大的原因。

工程应用

  • 实现或修改一个运算用 numerical gradient（数值梯度，常用 central difference 中心差分）核对 gradient 的实现。PyTorch 提供 torch.autograd.gradcheck 完成同样的检查。
  • loss 振荡或变为 NaN这通常说明单步更新过大，局部近似失效。首先将 learning rate 降低一个数量级再观察。
  • 阅读论文或代码中的 ∂ 与 ∇∂L/∂w 表示只改变 w 时 loss 的变化率；∇L 是这些变化率组成的向量，optimizer（优化器）据此更新 parameter。

Derivative 是局部变化率，gradient 是全部 parameter 的 partial derivative 组成的向量，chain rule 将复合运算的 derivative 表示为各步之积；backpropagation 即按顺序应用这三者。
